# Abismo

Survivor de fantasía oscura que se juega en el navegador: elige un héroe, baja por los cuatro círculos del Abismo rodeado de hordas, evoluciona y enfrenta a sus jefes. Al ganar, el viaje sigue por cuatro mundos más allá del Abismo hasta el que sueña todo esto.

- **Jugar:** https://matiasmartinez-z.github.io/abismo/
- **En itch.io:** https://matecitoz.itch.io/abismo
- **Tráiler:** https://matiasmartinez-z.github.io/abismo/media/abismo-trailer.mp4

Esta carpeta solo tiene el juego ya armado para publicarlo en una dirección fija. Desde el celular se puede instalar en la pantalla de inicio y se abre como una app, a pantalla completa.
